# Отклик интерфейса: «что должно случиться после действия?»

Правило: на любое действие человека сайт отвечает. Звуки синтезируются на лету (Web Audio, без файлов), все в одной тихой «бумажной» семье и выровнены по громкости. Выключаются в «Ещё → Звуки». На Android добавляется короткая вибрация. Если включено «уменьшить движение», анимации отключаются.

| Действие | Звук | Что видно |
|---|---|---|
| Нажать кнопку | глухой удар печати | кнопка продавливается, от пальца расходится оттиск краски |
| Вкладка, переключатель, флажок | тихий щелчок карандаша | вкладка пружинит, подсвечивается |
| Перейти по ссылке, пункт меню | шорох бумаги | страница «проявляется» из сепии, пункт подчёркивается от руки |
| Открыть «Ещё» / нижний лист | «поп» вверх | меню раскрывается из кнопки, лист выезжает снизу |
| Закрыть | «поп» вниз | |
| Перелистнуть тетрадь | шелест страницы | лист переворачивается с тенью; загнутый уголок подсказывает, что можно листать |
| Вклеить фото | скотч | фото прилипает с наклоном, искорки над листом, зайчик радуется |
| Убрать фото | отрыв бумаги | миниатюра отклеивается и улетает |
| Сменить раскладку | перетасовка бумаг | фото заново вклеиваются по одному |
| Печатать текст дня | еле слышный карандаш | курсор синей ручкой, выделение жёлтым маркером |
| Система услышала мотив («закат», «уют») | колокольчик, своя нота на мотив | появляется значок мотива |
| Записать голосом / стоп | два сигнала вверх / вниз | кнопка пульсирует |
| Выбрать песню | игла по пластинке | зайчик радуется |
| «Проявить» без фото | двойной глухой стук | подсказка трясётся, нужное место подсвечивается, зайчик показывает |
| Шаг проявки готов | щелчок | галочка дорисовывается от руки |
| День проявился | арпеджио колокольчиков | зайчик прыгает |
| Сохранить | печать + аккорд | на экран опускается штамп «СОХРАНЕНО» |
| Погладить зайчика | «бойнг» | зайчик пружинит; глаза всё время следят за курсором |
| Выбрать настроение 1–5 | аккорд: 1 мягкий и низкий, 5 яркий | 4–5 сердечки, 3 искорки, 1–2 капельки |
| Уведомление | шорох записки и тихий звон | записка на скотче выезжает снизу |
| Загрузка любой картинки | | фото проявляется из размытия, а не выскакивает |
