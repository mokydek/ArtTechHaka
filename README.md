# Оттиск — дневник атмосферы

> Фото помнят, как выглядел день. Оттиск — как он ощущался.

Кейс **ArtTech: Make the Invisible Visible** (Genesis Hackathon, 2026).
Человек пишет пару строк о дне, добавляет фото и песню — система читает настроение, свет и музыку и «проявляет» день как живую страницу дневника: со своей палитрой, обработкой фото, ритмом под песню, «погодой внутри», рукописной подписью и голосом. Каждый день лежит в отдельной папке с названием, которое система придумала по записи.

## Что умеет прототип

- **Полка тетрадей**: у каждой тетради своя обложка (9 процедурных: крафт, мрамор, гуава, птицы, лён, ночное небо, кожа, вырезанные буквы, коллаж из своих дней), выбор каруселью.
- **Тетрадь**: лента с датами и полоской фото, **«Листать»** — 3D-перелистывание как в бумажной книге, стена фото, год в пикселях, карта настроений.
- **Главная**: «В этот день» (год/месяц/неделю назад), серия дней подряд, подсказка «о чём написать сегодня».
- **Запись дня**: текст (подсказки, начала фраз, **диктовка** голосом + сохранение своего голоса), 1–8 фото (галерея или **камера «снять сейчас»**), **место и реальная погода того дня** (Open-Meteo), песня — ссылкой (Spotify, YouTube, Apple Music), поиском по названию или своим аудиофайлом.
- **Анализ на устройстве**, без облачных нейросетей:
  - текст — собственный русский лексикон: время суток, сезон, погода, места, люди, события, слова настроения (с отрицаниями и усилителями), сенсорные детали;
  - фото — доминирующие цвета (k-means в CIELab), свет, тепло, контраст, детали, «небо», огни в темноте;
  - музыка — темп (автокорреляция огибающей атак + октавная проверка), фаза долей, тональность (хромаграмма + профили Крумхансла–Кесслер), громкость, яркость тембра, плотность атак, пульс.
- **Воспоминание** — живая страница 4:5 (1080×1350): звучит песня, под ней — **звуки дня** (дождь, прибой, костёр, птицы, сверчки, город, винил — синтез на устройстве), кадры меняются в долю, формы пульсируют от громкости, подпись пишется от руки. Можно сохранить как видео (WebM/MP4 со звуком) и как **сторис 9:16**.
- **Скрапбук**: название из вырезанных букв, вырубные наклейки по предметам дня, узорный васи-скотч.
- **Шесть художественных приёмов**: Импрессия (Моне), Конструкция (Кандинский), Плёнка, Ма (японская пустота), Коллаж (Матисс), Ноктюрн (Уистлер) — выбираются по сумме признаков, параметры непрерывные.
- **«Почему так»** — для каждого дня видно, какое правило что изменило: «минорная песня → больше воздуха и приглушённый цвет».
- **Папка дня** с названием в 3–7 слов («Осенний парк и какао», «Ночь в офисе перед сдачей»): запись, фото, песня, воспоминание, обложка, озвучка, объяснение — можно скачать .zip.
- **Озвучка** голосом, подобранным правилами (темп, высота, паузы, мужской/женский), музыка при этом приглушается.
- **Год**: год в пикселях, доли приёмов, средний темп песен, «голоса года», карта настроений.
- **PWA**: ставится на телефон, оболочка открывается без сети.
- **Проявка полароида** (потереть / встряхнуть), **живое касание** (круги, разлёт частиц, дыхание на стекле и рисунок пальцем).
- **Небо того дня**: фаза луны на каждой странице, восход, закат, золотой час.
- **Музей мелочей**: запахи, звуки, свет, вкус, тепло и сказанные слова из всех записей.
- **Капсула времени**: письмо в будущее или запечатанный день — конверт с сургучом и ритуал вскрытия.
- **Альбом марок**: 21 марка за моменты, вручение со штемпелем.
- **Фильм месяца / тетради**: автомонтаж дней с их песнями и звуками, экспорт видео.
- **Открытка другу** (ссылка без регистрации) и **«Перенеси меня»** — перемотка к случайному дню.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
```

Облако — Supabase (анонимный вход + RLS, каждый видит только свои дни). Ключи по умолчанию прописаны в `src/lib/store/cloud.ts` (публикуемый ключ, безопасен для браузера); свои можно задать в `.env` (см. `.env.example`). Схема — `supabase/schema.sql`. Если облако недоступно, дневник работает локально (IndexedDB).

## Структура

```
src/lib/analysis   text.ts, lexicon.ts — язык; photo.ts — цвет и свет; audio.ts — аудиоанализ; music.ts — каталог и жанры
src/lib/design     system.ts — правила «настроение → форма» и объяснения
src/lib/render     engine.ts — страница и 6 приёмов; treatments.ts — мазки, постеризация, плёнка, тушь, коллаж, ноктюрн;
                   particles.ts — «погода внутри»; player.ts — звук, синхронизация, запись видео
src/lib/store      cloud.ts (Supabase), local.ts (IndexedDB)
src/lib            ambience.ts — звуки дня; place.ts — место и погода; covers.ts — обложки; prompts.ts — подсказки, серия, «в этот день»;
                   sky.ts — луна и солнце; details.ts — музей мелочей; stamps.ts — марки; film.ts — фильм; sfx.ts — звуки интерфейса
src/lib/render     ransom.ts — вырезанные буквы; stickers.ts — наклейки и васи-скотч
src/views          полка, тетрадь (лента/книга/фото/год/настроения), обложка, запись дня, папка дня, год, визуальная система
```

## Использованные инструменты

React 19, Vite, TypeScript, Supabase (Postgres, Auth, Storage), JSZip; шрифты Cormorant Garamond, Caveat, JetBrains Mono, Manrope (Fontsource, OFL); Web Audio API, Canvas 2D, MediaRecorder, Web Speech API; iTunes Search API (официальные 30-секундные фрагменты, песня целиком не хранится), oEmbed Spotify и noembed (название по ссылке), Open-Meteo (место и погода за день), BigDataCloud (название места по геолокации); шрифт PT Mono. Демо-фото — Unsplash (Unsplash License). Генеративные модели не используются: весь анализ и графика — собственный код команды.

Настроение — художественная интерпретация записи, а не психологическая или медицинская оценка.
